# Minqi Xia

Source for my personal website.

**Preview:** https://minqi-home.xiaminqi.chatgpt.site

## About

A quiet, content-led personal site for biography, current interests, notes, and selected links. The design is intentionally simple and follows a narrow, single-column reading experience.

## Development

Requires Node.js 22 or later.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Main files

- `app/page.tsx` — page content and structure
- `app/globals.css` — typography, layout, responsive styles, and dark mode
- `app/layout.tsx` — metadata and document shell
- `public/favicon.svg` — site icon
